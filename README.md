## 構成

| パス | 内容 |
|---|---|
| `index.html` / `style.css` / `script.js` / `images/` | LP本体（制作用） |
| `美容液LP完成版/` | サーバーにアップするファイルだけを複製したもの（LPで使っている画像・動画のみ） |

- スマートフォン向けのデザインを全幅で使う構成です（PC専用のレイアウトは持ちません）
- FV → 帰宅の映像は、スクロールに合わせて FV が引き、奥に固定した映像が立ち上がる演出（`script.js` の 5）
- OGP画像は `images/ogp.jpg`（1200×630）。`og:image` などのURLは仮のドメイン `lumea-beauty.jp` を指しています。公開するドメインに合わせて書き換えてください
